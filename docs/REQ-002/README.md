# REQ-002：私人绘图接入服务端统一写入

状态：已完成。日期：2026-11-25。依赖：REQ-001。分阶段证据见 VALIDATION，最终集成证据见 REQ-010。

## 目标与范围

为后续后台 AI 编辑建立持久的单一写入模式。绘图可从私人自动保存切换为服务端 Room；空间和分享权限独立；切换后不自动回退。现有未启用绘图继续自动保存。

- 持久化 serverManagedAt 与 sceneRevision，原子保存最终快照并切换模式。
- 版本冲突拒绝切换；旧标签页保存被拒绝，保留本地场景后加入 Room 合并。
- 私人所有者通过绘图 ID 加入 Room；访客仍需有效分享链接。
- 停止/重新生成分享只撤销旧链接的访问；不结束已启用绘图的服务端写入。
- 保留背景色与网格设置的同步、断线恢复与存储能力。
- 提供画布交接 hook/context，供后续 AI 面板调用；本需求不增加 AI 面板或执行模型。

## 验收

1. 数据、图片与写入模式在同一事务完成，失败或冲突没有部分切换。
2. 切换和并发旧保存串行，切换提交之后旧保存不能覆盖场景。
3. 其他成员不能通过 ID 加入私人绘图或读取其图片。
4. 分享撤销能移除旧链接的访客和无独立权限的登录成员，新链接连接不受旧链接清理影响。
5. 活动画布保留本地修改，旧自动保存不再排队；失败时恢复自动保存。
6. 新模式的背景色/网格不丢失，视角、选择、主题仍为本地设置。
7. 关闭最后浏览器保存后，可重新加载同一场景和模式；回收站、用户删除继续关闭对应 Room。
8. 测试、迁移、类型、国际化和 Lint 验证通过，证据记录在 VALIDATION。
