# T02 单画布邀请与 MCP 接入

状态：已完成。

方案：为成员当前绘图创建可撤销、可过期且只存哈希的授权；打开开关后生成包含实际实例地址和凭据的 Markdown，一键复制。MCP 逐请求核验授权，并仅提供该图的读取、控制、直接保存和回执工具，复用持久化任务及写入屏障。

验收：真实外部 AI 无需在网页配置模型或创建另一条聊天任务即可连接；不能越过绘图范围，撤销和过期对已建立连接同样生效。密钥不进日志或共享缓存，旧账号级工具不因新凭据被开放。

实现结果：已增加默认 24 小时绘图授权哈希表、独立六工具 MCP 服务、邀请来源任务与租约上下文、组件内一次性密钥和六语言复制说明。真实 HTTP 验收确认数据库只存哈希、工具范围仅限当前画布，伪造跨画布 context、轮换、过期和关闭后的既有客户端请求均被拒绝；真实 OpenCode 无需网页模型设置即可连接并获得持久化保存回执。完整证据见 [验证记录](../VALIDATION.md)。
