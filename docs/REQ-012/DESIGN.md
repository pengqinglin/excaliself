# 连接说明和画笔交接方案

状态：已实现；已按 [验收记录](VALIDATION.md) 完成真实客户端、浏览器和持久化验证。

## 部署与责任

当前应用已经在自身 HTTP 服务提供 `/api/mcp`，使用 Streamable HTTP，无需再部署一个 MCP 服务。新流程继续使用该端点，由绘图专用凭据选择受限工具集。外部 AI 负责调用模型和连接应用；应用的日常使用流程不要求选择模型或填写模型 API Key。

“把 MCP 装上”在这里是把远程端点注册到 AI 客户端。具备终端、配置写入或动态 MCP 连接能力的客户端可以根据说明完成注册；只支持静态连接配置的客户端需要在客户端完成首次添加或重载。没有 MCP 或可用 HTTP 工具的聊天页面，无法仅靠读 Markdown 获得执行能力。

正式部署地址必须能被 AI 所在机器访问。浏览器与 AI 在不同机器时，应用的 localhost 地址不能作为可用邀请地址；同机开发仍可用本机地址。文案说明这一实际连接条件。

## 打开 AI 协助与复制

1. 成员打开当前绘图的 AI 协助，先交接当前浏览器场景到服务端权威 Room，确保人工已画内容及图片已经保存。
2. 创建专属于这位成员和这一绘图的短期授权。建议默认 24 小时，可关闭或重新生成；不复用账号级个人令牌。
3. 面板展示可读 Markdown，一键复制端点、绘图链接／ID、专用密钥、期限、连接办法和协作规则。原始密钥只在此时交给用户，不写入日志或全局查询缓存。
4. AI 根据自己的客户端能力连接远程 MCP，先读取当前绘图，再执行外部对话中的指令。成员无需在网页另写一条任务才能授权这个流程。

复制文本的目标内容：

```markdown
# 参与这张 Excaliself 画布

画布：https://draw.example.com/draw/<drawing-id>
MCP：https://draw.example.com/api/mcp
认证：Authorization: Bearer <drawing-scoped-secret>
授权：只允许读取和修改这张绘图；在所示时间到期，可由成员关闭。

请在你的客户端连接该远程 MCP。连接后先读取当前场景和控制状态，
保留无关内容，只执行我在当前对话提出的绘图指令。
以保存操作回执确认修改已持久化；遇到人工接管、过期或撤销时停止写入。
交回 AI 后重读当前场景，不沿用人工编辑之前的计划。
若你不能注册或调用 MCP，请说明需要在你所在客户端完成的配置步骤。
```

以上展示邀请内容的意图，不是可用密钥或固定工具契约。实际复制内容由服务端生成，包含当前实例地址、一次性密钥、有效期和当前工具 schema 对应的使用说明。

## 授权与工具

当前个人令牌具备成员账号权限，不能直接复制进单画布邀请。新授权的服务端边界包括绘图范围、成员当前访问权、到期、撤销和控制版本；数据库只保存密钥哈希。

绘图专用凭据只暴露读取该场景、读取控制状态、直接提交修改和查询保存回执等工具，不暴露其他绘图、目录、成员私人对话或管理工具。即使客户端自行构造其他绘图 ID，服务端也拒绝。

普通 MCP `edit_drawing` 继续遵循 ADR 0003 的 Apply 提案流程。打开 AI 协助是明确授予当前绘图直接写入的动作；新流程复用 ADR 0004 的权威 Room、原子持久化、回执、重试去重及冲突检查，并由 ADR 0005 记录授权来源。

已有连接器 `assistant_*` 工具依赖任务领取和确认。邀请客户端通过独立的 `canvas_*` 工具建立受限的邀请来源任务与租约上下文；不把固定 runId 放入 Markdown，也不开放旧连接器工具给邀请凭据。暂停、恢复和重新读取推进工作上下文，旧上下文不能继续写入。

## 我来画与交给 AI

画布持续允许平移、缩放和人工编辑；连接面板使用不遮挡整张画布的布局，窄屏可以折叠。AI 状态与控制入口在面板折叠时仍可到达。

“我来画”先在服务端推进控制版本，阻止之后的新 AI 提交，再显示人工控制状态。已提交操作保持有效；用户随即在原画布移动、增加和删除元素。人工接管只暂停写入，关闭 AI 协助才撤销连接授权。

托管 Codex／OpenCode 连接器可以监听控制并终止自己启动的模型子进程；应用不能强杀外部独立 AI 的模型。对外部 AI 的保证是服务端拒绝它之后的写入，客户端收到暂停状态后应停止。

“交给 AI”先确认当前人工元素、场景设置和图片已抵达权威 Room，再开放新版本的 AI 写入。实现使用完整的场景同步屏障与持久化 ACK；图片上传和设置确认也包含在交接准备中，不以心跳 PONG 代替保存证明。

恢复后的第一次场景读取产生新工作上下文；旧上下文即使在恢复后迟到也不能提交。编辑仍携带受影响元素及标签／连线的 base 版本，冲突时重读，保留无关人工内容。

若 AI 客户端仍在通过工具轮询或等待，可发现交回状态后继续；若外部 AI 已结束本轮对话，页面按钮只恢复授权，用户还需在该 AI 对话说“继续”。复制说明或按钮不能无条件唤醒任意第三方聊天应用。

## 链接入口

先实现一键复制 Markdown，这能直接携带连接和操作说明。普通 `/draw/<id>` 或 `/share/<token>` 不充当 MCP 凭据。后续若只发一条链接，应设计独立的画布邀请链接，访问后可获得对应说明，且受相同范围、期限和撤销控制；不能把长期账号 Token 放在普通分享链接里。

## 验收

- 独立部署应用即提供远程 MCP；全程不在画板配置模型。
- 打开已画一半的图，复制说明给具备连接能力的真实 AI，首次读图后直接保存到原图，有持久化回执。
- 专用凭据无法读写另一张图；过期、关闭、换密钥后，已建立连接的后续请求也被拒绝。
- AI 正准备或提交期间点击“我来画”，迟到提交被拒；用户通过真实鼠标新增和拖动元素成功。
- 人工最后一笔在立即交回时也能被 AI 的首次读取看见；旧计划在恢复后被拒，冲突不得覆盖人工内容。
- 桌面与窄屏画布可操作，切换和关闭面板不冻结画布；操作回执可按既有冲突规则撤回。
- 区分已复制、客户端已连接、AI 正在工作和场景已保存；不把在线心跳当作任务成功。
- 六语言、用户指南、迁移、数据库并发及真实 HTTP MCP／浏览器验证与最终实现同步。
