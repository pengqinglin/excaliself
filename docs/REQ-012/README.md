# REQ-012：复制画布连接说明与人机交接

状态：已完成实施与验收。

成员打开“AI 协助”开关，在面板一键复制包含当前绘图、应用自带 MCP 地址和绘图专用授权的 Markdown，交给自己正在使用的 AI。应用负责画布访问、修改保存和协作控制；模型选择、模型凭据和推理由外部 AI 客户端负责。

用户可随时“我来画”，直接在原画布编辑；点击“交给 AI”后，AI 必须重读人工编辑后的场景再继续。外部客户端是否能自动注册 MCP、保持待命或接收唤醒，取决于客户端能力，界面应如实表达。

本需求补充独立的外部 AI 接入方式；该流程与 REQ-011 的常驻连接器分开提供。真实 OpenCode 客户端已通过本需求的 MCP 邀请完成读取、保存、人工接管和续画验收。
