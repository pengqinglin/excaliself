先顺序执行最终全量 Vitest、typecheck 和 build（它们共享 Paraglide 输出）；i18n 和 lint 无共享生成可单独执行。所有真实数据库测试只用 req001_test。应用联调用独立 req010_test，禁止读生产环境。

构建输出启动一个应用进程，以 Chromium/Playwright 操作真实登录和私有画布。连接器通过真实 /api/mcp HTTP，Codex JSONL 子进程协议用可控 fixture 覆盖暂停和回报；真实 Codex 如无登录，记录明确限制，不要求用户在执行过程中介入。

验证场景：从原画布发送；修改本地和另一个客户端；消息/接收/保存/最终结果区分；关闭页面仍完成；重新打开历史；暂停迟到提交、继续；撤回目标冲突；新成员看不到旧对话；窄屏无溢出。真实 WS smoke 验证初始化/场景/心跳/重连与最后离开落库。

检查正式迁移从旧库升级、snapshot 链和 schema 一致性。整理最终统计、日志与截图路径，更新各文档状态。只有实际通过的检查记录通过；当前机器 Codex 未登录会限制真实模型实测，但不阻塞实现、协议或受控端到端验证。
