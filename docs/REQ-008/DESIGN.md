# REQ-008 技术方案

单绘图/文件夹回收站引擎在同一事务内锁绘图后，按 ID 锁私有会话，取消非终态任务、推进控制版本、清租约并记录原因事件。读取工作允许本人执行端了解已取消状态；所有新写入仍拒绝回收站。永久删除和账号删除依赖已有外键 cascade，Team 场景保留。

撤销个人令牌/OAuth grant 或刷新重放删除 grant 后，先提交凭据删除，再按凭据条件释放未完成任务的租约并清在线记录。先提交删除避免 worker 持有 run 等待 credential、撤销持有 credential 等待 run 的锁反转；删除后的任何旧写入已被凭据验证拦截。进程崩溃留下的 lease 最多 60 秒后自然可重领。

连接器保留磁盘 worker UUID，同时每次进程运行增加随机执行实例 ID，MCP workerId 为二者组合。强杀后可能遗留的 Codex 子进程只能使用原租约；新实例不能以相同 workerId 复用活租约，过期后新代次屏蔽旧进程。优雅退出仍主动停止子进程。pending report 持久原 workerId，重启先按原身份幂等重报，然后领取新任务。

仅 worker 在线记录定期清理 30 天以上旧行，任务/历史不按离线自动删除。应用重启从已保存场景和任务数据库恢复，不把 Room 尚未 flush 的人工笔画当作可靠回执。错误事件不含私有正文或凭据。
