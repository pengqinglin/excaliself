# REQ-006 技术方案

使用画布内非模态侧面板，桌面可继续编辑，窄屏面板限制在画布范围；同时只打开评论或助手面板。入口同时放到顶部和窄屏菜单，只读画布不开放。

查询键包含当前成员和绘图；打开时幂等建立私人会话，历史按 newest-first 页反向渲染并支持加载更早消息。任务状态、连接及操作回执每 2 秒刷新，仅面板打开时查询。所有内容以 React 纯文本渲染，不插入 HTML。

发送时先 prepare 绘图并等待图片上传；请求 ID 在同一正文的未知响应后保持不变，成功后才清草稿。控制也使用固定请求 ID 和预期控制版本。关闭面板不调用 cancel。状态区区分指令保存、执行端接收、处理中、暂停确认、等待回复、离线和终态；保存卡只来自数据库操作回执。

交接冲突显示持久提示和手动重新加载入口，保留本地编辑直到成员决定。所有静态 UI 文案同批补齐六语言。撤回按钮在 REQ-007 接入。
