# REQ-011：可见的本地 AI 连接与真实续画

状态：已完成。

目标：成员在本地启动 Codex 或 OpenCode 后，能在设置和画布看见已连接执行端；AI 能读取当前画布的数据，在同一绘图上修改，并接受后续指令。

交付：OpenCode 常驻连接器、明确的本机 MCP 地址与启动命令、实际执行端名称、六语言文案和使用指南。通过真实模型读取已有画布及连续两次改图验证。

文档：[设计](DESIGN.md)、[任务](TODO.md)、[验证](VALIDATION.md)。

结果：OpenCode 1.19.6 使用真实配置模型完成两轮读取和续画，同一原生会话产生两份持久化回执。98 项自动测试、类型、六语言、Lint、应用与文档构建通过；独立画布的 11 项 WebSocket smoke 通过。完整证据及 Codex 未登录限制见验证记录。
