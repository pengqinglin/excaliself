# T04：任务领取、控制与租约

状态：已完成；依赖：T03。

## 方案

领取任务时验证成员和稳定令牌/OAuth grant 身份，绑定 worker 与租约代次。有效租约拒绝其他 worker 领取；超时后重领推进代次。心跳只延长租约，不代表已经接收消息。

成员暂停/继续需要预期控制版本；执行端确认最新控制与消息位置后才可回报进度、等待输入或最终结果。工作回报和消息在同一事务，回报 ID 记录请求摘要，以便丢失响应后安全重试。暂停仍允许心跳与暂停确认，禁止新的处理结果；取消立即结束任务。

## 执行与验证

1. 实现领取、读取工作、续租、确认、报告与控制接口。
2. 测试重复领取、过期重领、旧代次、旧控制版本、终态、凭据撤销与 OAuth 失效。
3. 测试补充消息使旧执行失效、暂停期间排队、恢复与最终结果重试。
4. PostgreSQL 并发验证领取和暂停/结果上报的串行结果。

## 结果

领取、工作读取、心跳、控制确认、暂停/继续/取消及执行回报已实现。16 项 PGlite 状态测试通过，覆盖精确租约到期、接管、旧版本、接收位置、凭据撤销、OAuth 轮换/失效、等待回复、暂停队列、终态及结果去重。10 项 PostgreSQL 事务验证通过；包含真实并发领取、结果重试、暂停竞态与凭据删除锁。
