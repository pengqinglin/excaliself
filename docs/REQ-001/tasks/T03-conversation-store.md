# T03：私有会话与消息存储

状态：已完成；依赖：T01、T02。

## 方案

数据库服务接受已有 Db。会话按成员和绘图唯一建立；读接口先检查会话归属与绘图访问权。写事务按绘图和会话取锁，分配消息、事件序号，记录请求去重键。用户指令自动创建或复用未结束任务。

列表使用 `afterSequence` 游标与有界 limit，取 limit＋1 条判断后续页。服务端函数只从认证中取得用户 ID，使用共享 Zod 输入契约。

## 执行与验证

1. 创建/读取会话，消息发送、历史与事件分页。
2. 验证 Team 对话隔离、私人权限、回收站只读和缺失行为。
3. 验证并发创建、消息排序、相同请求重试、相同 ID 内容冲突。

## 结果

会话创建/读取、指令发送、消息/事件分页及成员认证服务端函数已实现。8 个 PGlite 测试通过，覆盖会话复用、Team 私有隔离、越权、任务复用、重试冲突、输入校验、分页、回收站和访问变更；类型检查通过。真实并发验证在 T05 完成。
