## 目标

为外部 Codex 经 MCP 接收网页指令建立可靠的数据基础：私有会话、消息、执行任务、控制版本、执行租约和可重读的事件记录。

## 范围

- 一个成员在一份绘图上具有一个持久化会话，团队绘图上的会话同样私有。
- 消息排序、游标分页、请求去重；用户新消息创建或继续当前任务。
- 同一会话最多一个未结束任务；执行端领取和续租。
- 暂停、继续、取消、执行端确认、进度、等待回复和最终结果。
- 数据库约束、迁移、领域测试和真实 PostgreSQL 并发验证。
- 成员认证的服务端函数，供后续网页功能使用。

## 验收标准

1. 私人绘图仅创建者建立会话；团队成员分别建立私有会话且不能互读。
2. 消息事务内分配递增序号，分页稳定；重试返回原消息，冲突请求拒绝。
3. 首条指令创建任务，后续指令进入当前任务，结束后可建立下一任务。
4. 数据库保证每个会话最多一个未结束任务。
5. 领取操作互斥，过期租约可重新领取且代次增加；旧执行端不可上报或续租。
6. 暂停、继续及新指令推进控制版本；执行端确认最新输入后才可报告处理结果。
7. 已暂停、已取消、凭据失效、绘图回收站或无权访问均禁止新的执行写入。
8. 结果与事件在数据库持久化，重复结果不会重复生成消息或事件。
9. 迁移及适当检查通过，结果写入 VALIDATION。
