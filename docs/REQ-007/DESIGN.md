# REQ-007 技术方案

assistant_operations 新增 undoOf（唯一自引用）和 revertedAt。以成员身份执行，锁顺序保持 drawing update、conversation、run。检查原操作所有 after 元素的 version/nonce 与被修改设置字段；原 before 恢复为新版本，新建元素以新版本 tombstone 删除，不回退版本计数。

逆向场景、逆向回执、原回执 revertedAt 和事件同事务保存。若当前会话有活动任务，同事务推进 controlVersion 并暂停、追加成员暂停消息；提交后广播逆向增量。失败时不会暂停或部分修改。一个原操作只允许一次逆向提交，网络重试返回原逆向回执。

撤回期为 30 天，避免无限图片保留。Room 图片清理用 SQL 排除仍在撤回期内操作 before 引用的图片。超期或缺失图片拒绝撤回。历史回执仍保存到对话/账号/绘图删除；逆向操作不再提供再次撤回（不实现重做）。

面板按可撤回标志显示按钮，冲突以六语言提示；撤回已有任务的修改会暂停当前会话任务，成员决定后续指令。
